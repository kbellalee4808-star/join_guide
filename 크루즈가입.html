How to join

크루즈 가입 방법

무엇을 적는지부터 본인인증까지, 순서대로 따라오면 돼요.

무료

가입은 무료예요. 가입하면 바로 크루즈 상품 검색이 가능하고, 유료 플랜 업그레이드는 자유롭게 선택하면 돼요.

🔗

가입 링크는 추천해 준 분에게 받아요. 받은 링크를 열면 아래 항목을 적는 화면이 나와요.

1가입 화면에 적는 것

화면에 나오는 칸을 위에서부터 하나씩 채워요.

🪪
First name
이름을 여권과 똑같은 영문으로 적어요.
GILDONG
🪪
Last name
성을 여권과 똑같은 영문으로 적어요.
HONG
⚠️First name이 이름, Last name이 성이에요. 순서를 바꿔 쓰는 분이 정말 많아요.
⚠️닉네임은 쓰지 않아요. 여권과 다르면 크루즈 탑승 전에 여권을 첨부해 수정을 요청해야 해요.
📧
이메일 주소
자주 확인하는 주소를 적어요. 이메일 확인 칸에도 같은 주소를 한 번 더 적어요.
🔒
비밀번호
8자 이상, 문자와 숫자를 함께 넣어요.
🌏
국가 · 전화번호
국가는 Korea (+82)를 고르고, 휴대폰 번호를 적어요.
🙋
성별
해당하는 성별을 골라요.

로그인할 때 비밀번호 저장을 허용하세요. 아이폰은 암호 저장, 갤럭시는 Chrome 저장을 켜두면 다음부터 자동으로 입력돼요.

3바탕화면에 깔기 (앱처럼)

로그인한 상태에서 추가하면, 다음부터 아이콘만 눌러 바로 들어가요.

📱 아이폰

  1. Safari로 접속해요 (크롬은 안 돼요)
  2. 화면 아래 공유 버튼을 눌러요
  3. 메뉴를 내려 홈 화면에 추가를 눌러요
  4. 이름을 확인하고 추가를 눌러요

🤖 갤럭시

  1. Chrome으로 접속해요
  2. 오른쪽 위 ⋮ 메뉴를 눌러요
  3. 홈 화면에 추가를 골라요
  4. 추가를 누르면 아이콘이 생겨요
4본인인증하기

처음 한 번만 하면 돼요. 가입한 날 바로 해두세요.

1
로그인하면 환영합니다 화면이 나와요
2
아래쪽 선물상자 그림을 눌러요
3
KYC 인증하기를 골라요
본인인증 메뉴예요
4
여권 또는 운전면허증 사진을 찍어요
5
안면인증을 진행하면 끝나요
💡

여권으로 하면 훨씬 잘 돼요. 운전면허증은 인식이 안 되는 경우가 있어요. 밝은 곳에서 그림자 없이 찍어주세요.
